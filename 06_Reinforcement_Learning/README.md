# Reinforcement Learning

This folder contains reinforcement learning implementations, focusing on game AI agents and game-playing algorithms.

## Files

### Python Implementation
- **gym_pong_agent.py** - Pure Python implementation of Pong agent using OpenAI Gym

### Jupyter Notebooks
- **pong_agent_implementation.ipynb** - Detailed notebook implementation of Pong game AI agent

## Overview

These files implement reinforcement learning agents that:
- Learn to play Pong using Q-learning and policy gradient methods
- Interact with OpenAI Gym environment
- Demonstrate game-playing AI capabilities
- Include both Python script and notebook implementations
