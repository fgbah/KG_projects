# NLP & Question Answering

This folder contains projects and experiments related to Natural Language Processing, specifically focusing on Question Answering systems using BERT and DistilBERT models.

## Files

### BERT Q&A Implementations
- **bert_qa_advanced.ipynb** - Advanced BERT Q&A implementation with multiple iterations and improvements
- **bert_qa_tuning.ipynb** - Fine-tuning BERT for question answering tasks
- **bert_qa_with_teacher.ipynb** - BERT Q&A with teacher-student learning approach
- **bert_qa_v2.ipynb** - Second version with enhanced features
- **bert_qa_v3.ipynb** - Third iteration with further optimizations

### DistilBERT Q&A
- **distilbert_qa_implementation.ipynb** - Lightweight BERT variant for efficient Q&A

### Visualizations & Analysis
- **bert_qa_visualization.ipynb** - Visualization tools and analysis of Q&A model outputs

## Overview

These notebooks demonstrate how to build, train, and evaluate question answering systems using BERT-based models. The models are trained to extract answers from given contexts, with implementations ranging from basic to advanced with visualization and optimization techniques.
