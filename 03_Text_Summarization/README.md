# Text Summarization

This folder contains implementations of abstractive text summarization using various neural network approaches.

## Files

### Abstractive Summarization
- **abstractive_summarization_basic.ipynb** - Basic abstractive summarization approach
- **abstractive_summarization_pytorch.ipynb** - Abstractive summarization using PyTorch framework

## Overview

These notebooks explore abstractive text summarization techniques that generate summaries by creating new sentences rather than extracting existing ones. Implementations include:
- Neural abstractive summarization models
- PyTorch-based implementations
- Training and evaluation of summarization systems
