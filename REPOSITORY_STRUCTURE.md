# KG_projects Repository Structure

## Organization Overview

This repository has been reorganized into thematic folders for better organization and navigation. Each folder represents a specific domain or project type.

## Folder Structure

### 📁 01_NLP_Question_Answering/
Natural Language Processing projects focused on Question Answering systems using BERT and DistilBERT models.
- 7 notebooks covering BERT implementations, fine-tuning, and visualization
- **Key focus:** Extractive QA models, teacher-student learning, model optimization

### 📁 02_Text_Embedding_Similarity/
Text embedding generation and semantic similarity computation projects.
- 4 notebooks for embedding generation and similarity analysis
- **Key focus:** Sentence embeddings, similarity scoring, embedding pipelines

### 📁 03_Text_Summarization/
Abstractive text summarization implementations.
- 2 notebooks covering basic and PyTorch-based approaches
- **Key focus:** Neural abstractive summarization, text generation

### 📁 04_Sentiment_Analysis/
Sentiment analysis projects including aspect-based approaches.
- 1 notebook demonstrating aspect-based sentiment analysis
- **Key focus:** Fine-grained sentiment classification, aspect extraction

### 📁 05_Machine_Learning_Projects/
Comprehensive machine learning and data science projects.
- 8 notebooks covering Big Data Processing, clustering, and predictive modeling
- **Key focus:** Clustering (K-means, Mixture Models), prediction (loans), optimization

### 📁 06_Reinforcement_Learning/
Reinforcement learning implementations for game-playing AI.
- 1 Python script and 1 notebook for Pong agent
- **Key focus:** Q-learning, policy gradient, OpenAI Gym

### 📁 07_Utilities_Configuration/
Utility files, configuration, and dependencies.
- Documentation, setup files, and educational notebooks
- **Key focus:** Project setup, deep learning tutorials, web app templates

## File Naming Convention

All files have been renamed to be more descriptive and follow a consistent pattern:
- Use underscores for word separation
- Clear, descriptive names indicating the file's purpose
- Version numbers where applicable (v1, v2, v3)
- Descriptive suffixes (_basic, _advanced, _tuning, etc.)
