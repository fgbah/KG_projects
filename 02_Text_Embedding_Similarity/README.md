# Text Embedding & Similarity

This folder contains projects focused on generating text embeddings and computing semantic similarity between sentences and texts using transformer models.

## Files

### Embedding Generation
- **bert_sentence_embeddings.ipynb** - Generate sentence-level embeddings using BERT
- **embeddings_generator.ipynb** - General embedding generation framework
- **embeddings_batch_generator.ipynb** - Historical embeddings generator with timestamp

### Similarity Analysis
- **sentence_similarity_analysis.ipynb** - Comprehensive analysis of semantic similarity between sentences

## Overview

These notebooks implement various approaches to:
- Generate high-quality text embeddings using BERT and transformer models
- Compute similarity scores between text pairs
- Analyze and visualize semantic relationships
- Build embedding pipelines for large-scale text processing
